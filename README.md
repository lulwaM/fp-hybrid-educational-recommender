# fp-hybrid-educational-recommender
Educational recommender system for the Final Project module

## Dataset
To run the recommender, the OULAD dataset must be downloaded from this link: 
https://analyse.kmi.open.ac.uk/open_dataset

Once it is downloaded, the files must be extracted and uploaded to the data/raw/ folder.

npm install
python -m src.output.run    
uvicorn src.output.api:app
